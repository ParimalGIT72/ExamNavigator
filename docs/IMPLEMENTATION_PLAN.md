# Implementation Rules

The following rules apply throughout implementation:

- Each phase must be completed before the next phase begins.
- Every phase must include unit testing and integration testing.
- A phase is considered complete only after all tests pass.
- Code reviews must be completed before merging changes.
- Documentation must be updated whenever implementation changes the system behavior.
- No implementation should deviate from the frozen architecture without an approved architectural change.
